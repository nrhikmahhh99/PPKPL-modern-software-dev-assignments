# Version 2: Task Management App (Python/Flask + HTML + SQLite)

## Tech Stack Requirement Fulfillment
This version fulfills the assignment requirement to build at least one version of the application using a **non-JavaScript language**. The backend of this application is entirely written in Python using the Flask framework.

## Prerequisites
- Python (v3.8 or higher recommended)
- Flask (`pip install Flask`)

## Installation & Setup
1. **Navigate to the project directory:**
   ```bash
   cd week8/versi2-flask
2. **Activate your Python environment (e.g., Anaconda or venv):**
    ``bash
    conda activate cs146s
3. **Install dependencies:**
    ``bash
    pip install Flask

## How to Run
1. **Start the Flask server by running the following command in your terminal:**
    ``bash
    python app.py
2. **The server will start on http://localhost:5001 (to prevent port conflicts with Version 1).**
3. **The SQLite database (tasks.db) will be automatically created upon the first run.**
4. **Open your web browser and navigate to http://localhost:5001 to use the application.**
